## Ranked backlog

1. **01 MOC-L and 02 IHM-A**, if a timestamped imbalance feed and SPY minute bars are already in the data stack. Both are one-instrument or one-message tests with a declared holdout.
2. **05 MNA-D**, if a point-in-time deal tape exists. The paper's own warning is event-time annualization; the ledger has to be calendar time from the first run.
3. **08 NCAV-Q**, if point-in-time fundamentals exist. The $5 filter is part of the rule.
4. **04 INS-R**, after the Form 4 year-count integer is copied from the paper's classification section. Do not guess it.
5. **07 CURVE-B**, after the 2006 roll appendix is read. The 2015 paper is not a sufficient construction manual.
6. **06 SPIN-T**, once a tax-status spinoff census exists. Without it the sample will mix carve-outs into the result.
7. **03 OOPS-N** last among these. The primary book was not read, so a backtest would be a test of the secondary paraphrase.
