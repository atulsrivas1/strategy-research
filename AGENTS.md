# Research work agreements

Read README.md, docs/WORKFLOW.md, docs/BACKLOG.md, docs/RESEARCH_INDEX.md and current issue/Project evidence before choosing work. Use linked numbered stories and milestone gates; one active implementation initially. Source research and historical simulations are authorized within project scope; live trading, purchases and brokerage changes need separate instructions.

Freeze hypotheses, mathematics, data/availability rules, baselines, chronological splits, costs, trial budget and decision criteria before outcomes. Verify meaningful independent fixtures before batch experiments. Separate data adapters, calculations, signals, labels and accounting. Keep previously exposed data as development evidence.

Retain invalid runs, unsuccessful variants, scoped interpretations and corrections. Report source claims separately from independently tested results. Record actual review identity and limitations; self-review and CI are not independent human review. Documentation, verified delivery and linked acceptance precede Done. An inconclusive result can be a completed research story.

Publish sanitized methodology and aggregate summaries only. No original market datasets, detailed proprietary ledgers, raw chats, secrets or internal paths. A public status or report is not live-trading authorization. Current GitHub Project owns delivery status; docs/BACKLOG.md records ranked scope/dependencies. No unattended schedule is created by saved instructions.
